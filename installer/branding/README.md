# RelayBridge installer branding

`relaybridge-mark.svg` is the RelayBridge website mark imported from the separately
MIT-licensed public website repository at commit
`0c47c2b88cada345ebad06b7d26b08d2a6dcb9ac`. The source file is MIT-licensed and
owned by the RelayBridge project. The installer build deterministically renders
project-owned PNG and ICO derivatives for WiX branding; it does not use Microsoft,
WiX, or stock-art marks as RelayBridge branding.
